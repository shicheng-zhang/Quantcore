# User Guide

## Installation
Install Python dependencies and build the C++ components.

## First Run
1. Configure settings.
2. Download market data.
3. Start the API.
4. Open the dashboard.
5. Run a paper strategy.

## Typical Workflow
- Import data
- Generate indicators
- Backtest
- Analyze results
- Replay sessions
- Paper trade
- Monitor metrics

Live trading should only be enabled after successful validation.
